I started my development career in **2021**, so I now have about **{new Date().getFullYear() - 2021} years of hands-on experience** building applications and digital products.

My main focus has been **Flutter development**, especially building polished mobile apps with strong UI, clean architecture, and reliable performance. Alongside Flutter, I also work with **Node.js** for backend APIs and **Java** for core programming and Android-related development experience.

---

### Flutter

Flutter is the center of my development journey. I enjoy using it to build cross-platform mobile apps with smooth performance, reusable components, and clean user experiences. I focus on writing maintainable code and creating interfaces that feel modern, responsive, and production-ready.

### Node.js

I use Node.js to build backend services, APIs, and integrations that support mobile and web applications. I like its flexibility and how well it fits into full-stack workflows, especially when building fast, practical products.

### Java

Java gave me a strong programming foundation and helped me understand object-oriented design, application structure, and scalable development practices. It also supports my Android and backend understanding when working across different platforms.
